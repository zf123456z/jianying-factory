✅ **克隆音色三种建法：** 录制音频 / 从本地视频提取音频 / **直接导入音频文件**（用 `E:\张总语音\讲产品.mp3` 33秒即可）

## 一、口播视频标准制作流程（按优先级）
### 1. 音频处理（第一步！音是根）
✅ **必做：**
- 人声增强：选中配音→音频面板→音量拉到120%，开启「人声增强」，人声更透亮
- 音频降噪：开启「降噪」，消除背景杂音
- BGM自动闪避：BGM轨道右键→开启「音频闪避」，人说话时BGM自动压到20%，没人说话时自动回到40%
- 首尾淡入淡出：BGM首尾各加500ms淡入淡出，不突兀
- 静音自动裁剪：配音开头结尾空白全部剪掉，一开口就有声音

### 2. 字幕处理（100%用官方识别，不要自己写！）
✅ **爆款字幕参数：**
- 字体：黑体/思源黑体粗体
- 字号：10-12号（1080P竖屏）
- 颜色：黄字黑边，描边宽度3
- 位置：画面下1/3处，不挡人脸
- 动画：入场「打字机」，时长0.2秒
- 重点词自动高亮：红底白字，重点词（数字、"免费"、"第一步"）自动变色

### 3. 画面处理
✅ **必做效果：**
- 美颜：磨皮30、瘦脸10，自然不夸张
- 滤镜：选「清晰」「原生」「自然」，强度50%，不要重滤镜
- 智能补帧：导出时开「智能补帧」，画面更丝滑
- Ken Burns运镜：每10秒缓动放大105%，不呆板
- 原视频静音：口播视频绝对不要原视频的环境音！

### 4. 包装效果（分风格一键套）
| 风格 | 调用哪个官方功能 | 自动加什么 |
|---|---|---|
| 科技风 | 智能包装→科技风 | 科技标签贴纸、扫光特效、科技感转场音效 |
| 干货风 | 智能包装→知识分享 | 数字序号贴纸、重点高亮块、提示音效 |
| 情感风 | 智能包装→生活Vlog | 柔焦滤镜、暖色氛围、舒缓转场 |
| 带货风 | 智能包装→营销带货 | 价格标签、"赶紧冲"贴纸、促销音效 |

### 5. 转场与音效
✅ **标准配置：**
- 转场：片段之间加「叠化」0.3秒，不生硬
- 音效：关键词弹出加「叮咚」提示音，段落切换加「swish」扫音
- 片尾：最后3秒自动加「关注」贴纸+引导音效

### 6. AI对口型（真人口播嘴型对齐，核心！）
> 想让视频里的人物嘴型跟着新配音动，必须用剪映官方「AI对口型」，AI会重建嘴部让口型和声音同步。

✅ **准确入口（电脑专业版）：**
- 选中轨道里的**人物视频片段**（或人物图片）→ 右侧**属性调节面板 → 画面基础** → 勾选「**AI对口型**」（手机版：选中视频条→下方工具栏「AI对口型」）
- ⚠️ 不是「数字人」，数字人是虚拟形象，对真人视频要用「AI对口型」

✅ **两种生成方式（选「用音频生成」才是和我们配音对齐）：**
1. **用音频生成（对口播场景，必选）**：点「添加音频」→ 从本地选我们已生成的配音MP3 → 它会用这段音频驱动嘴型 → 生成
2. 用文案生成：输入台词+选音色，适合没有现成配音时

✅ **生成模式选择：**
- 普通模式：嘴型自然、动作稳定（口播视频推荐）
- 灵动模式：表情更丰富夸张（适合剧情/搞笑）

✅ **对齐三件套（顺序不能乱）：**
1. 先固定配音（人声音轨）
2. 再官方识别字幕（字幕跟着配音走）
3. 最后AI对口型（嘴型跟着配音走）
→ 三者都以配音为基准，天然一致，永不跑偏

✅ **生成后必查：**
- 对口型会重建视频片段，**重新检查总时长**，确认视频/BGM/字幕仍然在配音结束点截断
- 个别字没对上：选中片段→「剪辑」→「变速」→常规变速±0.1倍微调
- 人物要求：正面、脸部清晰、画面中占比够大，侧脸/背身/低头无效
- 这是SVIP高级功能，免费版可能无入口或带水印；入口在选中视频后右侧面板才出现

## 三、绝对不能踩的坑
1. ❌ 不要自己写字幕时间！必须用剪映官方识别，100%准
2. ❌ 不要留原视频的声音！口播视频原视频必须静音
3. ❌ BGM音量不要超过40%！绝对不能抢人声
4. ❌ 不要写死特效ID！瞎编的ID剪映打开就丢
5. ❌ 不要让片尾黑屏！所有轨道时长必须和配音一致
6. ❌ 不要每秒切一次素材！单素材循环每段至少8秒
