# 剪映工厂 - 口播成片完整工作流

## 场景：从文案到成片

### 输入
- 口播文案（txt文件）
- 素材文件夹（视频/图片/BGM）

### 流程

#### 1. 读取文案
```python
builder = VoiceoverBuilder("文案.txt", "./素材/", "./成片/")
segments = builder.read_script()
```
按段落/句号自动分段，每段对应一个镜头。

#### 2. 素材匹配
- 自动扫描素材文件夹
- 根据文案语义匹配最合适的画面（B-roll）
- 图片素材默认展示5秒

#### 3. 配音
- 剪映TTS：选择合适的声音（男声/女声/情感）
- 或使用用户已录好的口播音频

#### 4. 字幕
- 自动识别语音生成字幕
- 智能错别字修正
- 统一字幕样式（字体/大小/位置/描边）

#### 5. 配乐
- 根据视频节奏自动匹配BGM
- 自动卡点
- 人声优先（BGM自动闪避）

#### 6. 导出
- 分辨率1080p
- 帧率30fps
- 格式MP4

## 批量模式

```python
# 一次处理多个文案
scripts = ["文案1.txt", "文案2.txt", "文案3.txt"]
for s in scripts:
    builder = VoiceoverBuilder(s, "./素材/", "./成片/")
    builder.build()
```

## 行业模板

- 餐饮口播：暖色调 + 美食BGM
- 服装口播：快节奏 + 潮流BGM
- 教育口播：稳重色调 + 轻BGM
