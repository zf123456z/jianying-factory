# 剪映工厂 - GUI操作指南

## 启动剪映
1. 定位剪映主程序：`find_jianying.py`
2. 启动并等待主界面加载
3. 自动关闭促销弹窗（按ESC）

## 新建草稿
1. 点击"开始创作"
2. 等待剪辑界面加载
3. 确认时间线已就绪

## 导入素材
1. 点击"导入"按钮
2. 在文件选择器中选择素材
3. 拖拽到时间线

## 智能字幕
1. 点击顶部"字幕"
2. 选择"智能字幕"
3. 点击"开始识别"
4. 等待识别完成

## 导出
1. 点击右上角"导出"
2. 设置分辨率/帧率
3. 选择输出路径
4. 点击"导出"并等待完成

## 常见弹窗处理
- 促销弹窗：按ESC关闭
- 登录弹窗：请求用户接管
- 积分/VIP弹窗：请求用户确认
- 文件覆盖提示：确认覆盖
