# 爆款文案前期工作流（v7.4 新增）
> 用户一句话 → 全网热点 → 爆款拆解 → 原创文案 → 用户确认 → 进入配音/剪辑。
> 本文件是"青出于蓝"的第一块：上游只会"给文案做视频"，我们还会"给主题找热点、写爆款"。

---

## 一、热点发现（用户只给一句话/主题时）

### 1. 热点来源（按优先级）
| 来源 | 用哪个搜索 | 时效 |
|---|---|---|
| AI/科技圈 | 今日头条、36氪、量子位、快科技、博客园 | 当天/近3天 |
| 全网热榜 | 微博热搜、知乎热榜、抖音热榜 | 当天 |
| 财经/职场 | 中国经济网、36氪、微信公众号爆文 | 近7天 |
| 英文圈 | TechDG、OpenAI/Anthropic/Meta 官网、Finder | 近7天 |

### 2. 热点评估五维（打分 1-10，总分≥32 才值得做）
1. **新鲜度**：今天/昨天的新闻 ≥8；一周内的 ≥6；炒冷饭直接弃
2. **情绪值**：能不能让普通人有"焦虑/惊喜/共鸣/愤怒"——没情绪不爆
3. **利益相关度**：和"普通人的钱/工作/生活"相关度越高越爆
4. **可跟风度**：能不能从普通人视角切入（"这事跟我有什么关系"）
5. **争议度**：有对立观点更容易引发评论（但避开敏感政治）

### 3. 三个坑
- ❌ 只找"行业新闻"不找"跟普通人有什么关系"——别人不关心
- ❌ 用过期热点（>1周基本凉了）
- ❌ 搬运原文——必须原创改写（见三）

## 二、爆款拆解（拿到热点后先拆再写）

### 1. 拆爆款的骨架（对标抖音/视频号爆款）
```
钩子(0-3s)    —— 反常识/痛点提问/结果前置，一句话抓住人
冲突(3-15s)  —— 现状有多糟/别人多爽/你不做会怎样
转折(15-30s) —— 给出新认知/新方法，打破"原来如此"
干货(30-50s) —— 3 条以内，每条一句人话，可执行
行动(最后5s) —— 关注/评论关键词/领取资料，给明确指令
```

### 2. 拆爆款的情绪曲线
- 前三秒必须有"情绪钩子"（惊讶/焦虑/好奇/贪婪）
- 中间每 10 秒一个小高潮（数字、案例、反转）
- 结尾必须"给甜头"（免费资料/清单/口诀）→ 促进评论

### 3. 爆款标题公式（任选）
- 反常识型：`普通人还有活路吗？在AI时代，答案是有，但不在你以为的地方`
- 数字型：`记住3句话，AI获客再也不求人`
- 痛点型：`为什么你做了3年短视频，还是没赚到钱？`
- 身份型：`如果你是卖猫粮的，这篇能帮你多赚10倍`
- 悬念型：`2026年最被低估的一个词，90%的人没听过`

## 三、原创改写（青出于蓝的核心，绝不洗稿）

拿到热点后按以下步骤**重写**成用户视角的原创文案：
1. **换主角**：把"OpenAI/Meta 又发布…"换成"这对你意味着什么"
2. **加数字**：具体金额/时间/倍数（"闲鱼9.9元教程卖出上万份"比"很多人靠教程赚钱"强10倍）
3. **加案例**：一个真实小案例（楼下小店/朋友/评论区反馈），比十个道理有用
4. **留钩子**：结尾给"评论区打XX，我发你完整版"的引导词
5. **控制长度**：口播 40-60 秒 = 200-260 字（普通话语速约 4.5 字/秒）

### 输出格式（给用户确认）
```
【爆款标题】xxx
【口播文案】xxx（200-260字，按钩子-冲突-转折-干货-行动结构）
【引导评论】评论区打"xxx"，我发你完整版
【选题依据】为什么这个热点值得做（1句话）
```
用户确认后才进入：配音 → 素材 → 剪映识别字幕 → 包装。

---

## 四、通用铁律
1. 素材永远固定用户指定的形象视频（如 `张总形象.mp4`），不扫文件夹
2. 文案必须**用户确认**后再生成长视频（一句话成片的傻瓜体验 + 不返工）
3. 爆款 ≠ 标题党：标题可以炸，正文必须有真东西（数字/案例/方法）
4. 涉及政策/医疗/财经类话题，只做"科普+个人观点"，不承诺收益、不荐股
