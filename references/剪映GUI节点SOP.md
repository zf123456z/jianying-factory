# 剪映工厂 · 受控窗口 GUI 节点 SOP（实测版）

> 本 SOP 基于 2026-09-24「护城河口播_张总形象_克隆声版」全流程实测跑通记录。
> 坐标系：受控桌面 0-1000 千分比（1920x1080 屏幕）。**每次点击前必须先 cu.screenshot() 取新帧，坐标会因面板状态漂移，本表坐标是"上次成功值"，不是"永远正确值"。**

## 铁律（违反必出错）
1. 剪映只能通过 `cu.list_apps()` + `cu.launch_app(精确名)` 在受控窗口里启动，**绝对禁止** pyautogui / Popen / 桌面双击图标。
2. 每一步 GUI 动作后必须重新截图再取下一步坐标。
3. 素材/配音/BGM 全部由 engine_v2 写进草稿，**GUI 里不拖拽素材**。
4. 字幕必须用剪映官方「识别字幕」，禁止自写对齐。
5. 用户要求"放草稿箱即可"时，做完换音色+识别字幕+包装就返回首页，不点导出。

## 节点流程（实测通过顺序）

### 节点0：启动剪映（约30秒）
```python
import seed_computer_use as cu
apps = cu.list_apps()
matches = [a for a in apps if ("剪映专业版" in a.name and "卸载" not in a.name)]
# 唯一匹配后：
cu.launch_app(matches[0].name)   # 返回 accepted_unverified 是正常
time.sleep(12)                   # 等窗口出现
cu.screenshot()
```
- 应用列表有「卸载剪映专业版」干扰项，必须过滤 `"卸载" not in a.name`
- launch_app 只接受精确 App.name（含 # 后缀），大小写/缺后缀都会被拒

### 节点1：打开草稿（约20秒）
- 双击草稿**缩略图区域**（y≈700），不是文字区（y≈740）
- 实测：单击(348,740)无效，双击缩略图(360,700)成功打开
- 打开后右侧「草稿参数」面板显示 保存位置=D:\AI工作区\剪映草稿\<草稿名> 即成功

### 节点2：选中配音轨（约3秒）
- 配音轨在时间轴 y≈800 区域，点击(150,805)
- 成功标志：右侧出现音频面板（基础/换音色/声音效果/变速/改词翻唱）

### 节点3：换音色·克隆音色（2026-09-27 实测校准，剪映 11.5）
> 本节点坐标全部为 2026-09-27「统一入口验证_默认素材」受控窗口实测成功值，替换旧版全屏坐标。

| 步骤 | 坐标（千分比） | 等待 | 实测依据 |
|---|---|---|---|
| 点「换音色」标签 | (777,46) | 2s | 实测 OK（旧值793,52会偏） |
| 点「克隆音色」分类 | (769,132) | 3s | 实测 OK（点偏上如y≈120不切换列表；列表出现"张总专属/点击克隆/音色04"） |
| 点「张总专属」音色 | (870,185) | 2s | 实测 OK（OCR区间850-890,180-200） |
| 点「应用」按钮 | (970,505) | 5s | 面板漂移区(940-990,490-520)，点前必须重截图取新坐标 |
| 弹窗「确认使用」 | (525,520) | 60-90s 等待处理 | 实测 OK（弹窗按钮漂移到490-530，需重截图） |
- 成功标志：时间轴配音轨标记「换音色 张总专属」，积分余额减少（本次扣212，1964→1752）
- 处理完成前弹窗会显示「1个任务处理中」进度百分比，完成后消失
- 坑：点「换音色」标签位置偏差会打开「声音效果」面板（热门/环境/美化），此时需重截图像正坐标
- 坑：克隆音色分类点击后若列表仍显示「真人播客女/大叔」等热门音色，说明点偏了（标签中心是y≈132，不是y≈110-120），重截图再点
- 前置条件：需已克隆过音色（音频→换音色→克隆音色→点击克隆→录入声音→保存「张总专属」），且账号有足够积分

- 成功标志：回到剪映首页，草稿列表第一项出现新草稿（名称+大小+时长）
- 草稿大小会比初始增大（本次22.6M→24.8M，因包装素材+字幕），属正常

## 常见失败与恢复
| 现象 | 原因 | 处理 |
|---|---|---|
| 点完没反应/打开了错面板 | 坐标漂移 | 重截图，按新帧修正坐标，别连续盲点 |
| 剪映没起来 | launch 未匹配/重复 launch | 确认过滤"卸载"，accepted_unverified 后等12s再截图 |
| 双击没开草稿 | 点在文字区 | 改点缩略图 y≈700 区域 |
| 换音色处理中卡住 | 云端处理需时间 | 等60-90s再截图，别点取消 |
| 智能包装生成中 | 需匹配音效 | 等90-150s，别点取消 |
