# 拆解档案 04：模板工具平台结构模式（2026-10-12）

> 定位：本档案只做【模板工具平台】（剪映模板中心/开拍/快影/秒剪/Canva/稿定设计/醒图）的高级模板结构调研，作为真实爆款拆解（另三位同事负责抖音/小红书/B站）的交叉验证与补充。
> 独特价值：① 模板平台最先进、最"标准化"的结构模式（它们把爆款结构沉淀成了可套用的模板）；② 与我们的引擎（VectCutAPI，竖屏 1080x1920）逐条对照可实现性。
> 版权铁律：只沉淀"可执行的样式预设 + 方法论"，不照搬任何模板的具体文案/素材/音乐；预设均为通用规则。
> 诚实规则：样张图全部经 image_search 获取并用 OCR 坐标拆解；拿不到样张图的平台（开拍/秒剪）已如实标注"仅凭文字描述，视觉证据不足"。

## 三、对我们模板库的最有价值增量 TOP5

1. **色块底/圆角背景参数化 = 模板平台的"框与卡"核心工艺**。12 个结构里有 6 个依赖色块/卡片承载文字（封面锁版、金句弹卡、CTA 条、标题框、系列胶囊、要点卡）。我们的 add_text 已支持 background_alpha/background_color/background_round_radius——应系统化沉淀"色块框"预设（半透明黑块底 0.6-0.85、CTA 红条 0.9、胶囊圆角 0.5-1.0），这是零成本最高杠杆的增量（立即落地）。
2. **知识要点卡·编号列表结构**（标题 + 3-4 条编号要点 + 总结）。模板平台与知识赛道交叉强项，适合知识口播/干货内容，我们目前 style_templates.json 无此档——新增 knowledge-point-list 预设，逐条 0.3s 错峰渐显 + 编号高亮（需小改：多行自动布局）。
3. **封面大字锁版 + 系列标签（右上角 pill）**。剪映百搭封面与 Canva 缩略图都靠"统一锁版 + 系列标签"沉淀频道视觉资产——新增 jianying-cover-lockup 预设，右上角标签用 transform_x + 背景圆角近似（需小改：pill 标签近似渲染）。
4. **促销档：倒计时/价格红色强调层 + CTA 色块条**。稿定大字报结构是"双屏广告"的促销变体，与现有 gold/hot 档互补——新增 gaoding-countdown-bigtext 预设（3 分钟可实现），红 #FF3B30 强调层 + 红底白字 CTA 条，直接复用 add_text 色块底。

- web_fetch ×2（CapCut Cover Page 模板中心分类页、确认 cover/album/logo 模板即拖即用体系）。

**限制与诚实声明**：
- 本环境无浏览器（浏览器由协作同事独占），所有模板平台的 App 内模板库（需登录）均无法直接浏览；开拍、秒剪、醒图官方模板库**未获取到官方样张图**，对应结构基于公开教程/产品描述，已逐条标注"视觉证据不足/文字描述为主"。
- 剪映封面预设样张来自第三方卖家推广图（老鱼/淘宝），非官方模板库截图，但九宫格内单张封面结构清晰可拆。
- 快影样张为 App 宣传截图（CUSTOM COVER 页面），非成品模板帧。
- 所有图片均为第三方内容，按来源以链接引用，仅作结构拆解用途；**未将任何截图素材当作模板资源使用**。
- 预设 JSON 全部为通用排版规则，不含任何平台的原创文案、素材或音乐；动画名均在引擎允许枚举内（打字机/渐显/弹入/放大/开幕），transform_y/transform_x 均通过安全线校验（字号≤10→|y|≤0.80；11-16→|y|≤0.75；>16→|y|≤0.60；|x|≤0.45）。
