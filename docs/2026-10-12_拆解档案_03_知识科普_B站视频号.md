## 二、逐条五步法拆解

### 样例 1｜抖音 · 心梗真相（150.3 万赞）

**画面证据**：内帧图 NA（抖音反爬，见〇）；封面样式参考（image_search 已 Read 的同类"心梗预警"封面：白大褂医生居中 + 黄黑大字 + 血管红细胞医学背景，来源爱奇艺账号缩略图，非原帧）；口播分段结构（video_search 真实文本）。

**第 1 步 画面分区**（推断，基于同类封面+口播节奏）：
- 顶部 +0.6~+1.0：大字标题区（"心梗真相"类四字主标题，黄/白大字+黑描边）
- 中部 0~+0.5：素材区（3D 血管模型/心脏解剖动画，或医生口播画面）
- 底部 -0.4~-1.0：字幕条 + 章节要点（求救信号/自救/预防逐段上屏）
- 要点卡排布：纵向列表（每章一条），transform_x=0 居中

**第 2 步 文字层级**（推断+文本证据）：
- 主标题：相对 100%（约 20 号），黄 #FFD400 或白，加粗，黑描边，顶部，打字机
- 章节小标题：约 62%（10 号），白，黑描边，中部偏上，如"身体求救信号"
- 要点句：约 56%（9 号），白，底部字幕位，半透明黑底条
- 强调词（如"自救""预防"）：红色 #FF3B30 或黄，占比最小
- 文本证据：开头用案例钩子（"29岁小伙被气心梗…把'是我'打在弹幕上"）→ 章节化推进

**第 3 步 动画节奏**（推断，知识科普通用规律）：
- 标题先出（0s 打字机）→ 章节要点逐条弹出（约每 0.6–1.2s 错峰）→ 总结/自救措施收口
- 文字常驻不退出，只入场

**第 4 步 素材规则**：
- 3D 医学模型（血管/心脏）+ 实拍 + 大字警示色块；素材与章节语义一一对应
- 情绪钩子前置（真实案例/名人猝死），知识后置

**第 5 步 归纳**：
- "大字标题 + 分段要点 + 情绪钩子前置"；评论互动设计（"打'是我'在弹幕"）提升话题型数据

### 样例 2｜抖音 · 20 个经济学小知识（8.9 万赞，编号章节化核心参照）

**画面证据**：封面 NA（video_search 返回 540x719 竖屏封面缩略但无下载 URL，抖音反爬）；内帧 NA；编号结构与文案量（video_search 真实文本："01.什么是洗钱？…20.什么是杠杆？"，"16分钟8756字"）；题材为动画科普（"小猫给你讲清楚"，哈基米风格，标题原文含 #动画 #哈基米）。

**第 1 步 画面分区**（推断，基于编号结构+动画科普类型）：
- 顶部 +0.7~+1.0：当期知识编号+标题（如"经济学小知识 01"），编号徽标独立
- 中部 0~+0.6：动画讲解区（小猫角色+示意图），当期要点文字卡随讲解出现
- 底部 -0.6~-1.0：字幕/补充条
- 要点卡排布：纵向列表，每条知识点一块"编号+短句"卡，transform_x=0 居中

**第 2 步 文字层级**（推断）：
- 编号徽标（01/02/03…）：黄 #FFD400 加粗，约 87%（14 号）或更小，置于要点卡左端/卡头
- 当期标题：白加粗，约 62%（10 号）
- 要点正文：白，约 56%（9 号）
- 每条要点以"编号丨一句话"结构出现 → **数字序号要点卡**

**第 3 步 动画节奏**（推断）：
- 标题先出 → 要点逐条弹出 → 总结收口；编号递增时"卡点"推进（每章一条）
- 长视频分章，每章独立开合，章节间留停顿

**第 4 步 素材规则**：
- 简约动画 + 单角色讲解 + 色块点缀；文字承载信息主体（8756 字长文案 = 文字驱动型干货）
- 素材与知识点语义对应（洗钱→小猫+银行元素类）

**第 5 步 归纳**：
- **"数字编号 + 一句话要点卡 + 逐条弹出"是竖屏知识长视频的顶级结构**；低评论率高收藏预期=纯干货型

### 样例 3｜B站 · 坠入奇点（49.6 万播放 / 收藏率 64.9%）

**画面证据**：官方原封面已 Read（1920x1080）：黑底宇宙深空+黑洞视界+吸积盘光晕+对称宇航员队列（白/红剪影）；画面下部黄字主标题"永恒6分钟"、白字疑问副题"在黑洞里看见100个自己？"。简介章节结构（web_fetch 真实返回：⏱️ 为什么主观6分钟是远方一生 / 👁️ 光子球看见无数个自己 / ⚫️ 穿越视界有无感觉 / 🍝 意大利面化）。

**第 1 步 画面分区**：
- 封面分区：上部 0~0.55=素材区（黑洞/宇航员）；下部 -0.45~-0.10=标题区（黄主标题+白副题）
- 内页（推断，基于同类硬核科普叙事）：顶部章节标题/进度，中部 CG 演示，底部字幕

**第 2 步 文字层级**（封面为实据）：
- 主标题"永恒6分钟"：黄 #FFD400，加粗，黑底高对比，位于画面下部（y≈-0.35~-0.20 换算），约覆盖画面宽 40%
- 副题"在黑洞里看见100个自己？"：白，非加粗，位于主标题下方（y≈-0.15 换算），疑问式副题
- 内页章节点（简介层）：emoji 图标+短句 = 章节化索引

**第 3 步 动画节奏**（推断）：
- 长视频（9:45）章节化叙事：章节标题/进度条常驻，随章节切换渐显/溶解
- 封面→内页开场：标题入场后切入正片

**第 4 步 素材规则**：
- 深空 CG + 科幻美术 + 沉浸式音效；黑底保证白/黄字对比
- 系列化（谜题 01/14）→ 合集运营沉淀粉丝

**第 5 步 归纳**：
- **"黑底 + 大字黄/白标题 + 疑问式副题 + 章节化索引（emoji/编号）"** 是 B站硬核科普封面与长视频章节的通用范式；收藏率 64.9% 印证"知识类爆款靠收藏率"

## 四、与现有模板对比（明确增量）

**现有基线**：

## 五、平台差异观察（B站 / 抖音 / 视频号）

### B站（重点）
- **形态**：主流横屏长视频（5–15 分钟），硬核科普以天文/物理/医学 CG 为主；封面是"大字标题"主战场。
- **封面规律**（3 张已 Read 实据）：黑底深空素材 + 白/黄大字 + 悬念/对比/榜单式钩子；主标题或居下（坠入奇点：黄"永恒6分钟"+白疑问副题）或居左上（十大恒星：黄"已知最大恒星排名"）；VS/排行等符号化副信息用黄色。
- **章节化在"简介时间轴"与"系列化"层**：简介 emoji 分点（坠入奇点 ⏱️👁️⚫️🍝）、00:00/00:30 时间轴（布洛芬）、合集编号（谜题 01/14，合集 252.9 万播放）。内页排版偏叙事+字幕，竖屏要点卡少见。
- **数据特征**：知识爆款收藏率极高（坠入奇点 64.9%），弹幕氛围强；长视频=深度留存好。

### 抖音知识区
- **形态**：竖屏短平快；硬核健康/生活科普（心梗、鸡蛋血管、成瘾）与动画长视频（20 个经济学）双线。
- **排版规律**：大字标题 + 编号要点卡 + 章节化推进密集出现（"第八种""冷知识2""01-20""器官1-8"）；3D 模型/动画承载知识点；情绪钩子前置（真实案例、弹幕互动指令）。
- **数据特征**：评论率高=话题型（心梗 7.5%）；评论率低=纯干货型（经济学 0.7%，收藏预期高）；爆款多来自"抖出健康知识宝藏/科普新锐扶持计划"等官方话题聚合。

### 微信视频号
- **公开数据缺失**：无公开单条播放/点赞接口（需微信生态登录），本档无法获取单条爆款数据与帧图。
- **账号体量级判断**（来源标注）：
  - 「常岩道」（岩土工程师科普）：视频号 3 年累计浏览近 3 亿（长江网 2025-12 报道）
  - 「大圆镜科普」（AIGC 科普）：微信视频号 5 次进入"科技互联网"影响力日榜前五并登顶（中国科技网 2025-09）
  - 「意公子」（艺术史知识博主）：全网千万粉丝（腾讯新闻 2025-10）；「中气爱」全平台近 3000 万粉丝（复旦新闻网 2025-10）；「一颗柠檬子」历史科普单条 10 万+ 点赞（触电新闻 2026-09）
- **推断（非实证）**：视频号知识科普题材偏中老年健康/历史人文/政务农业，头部账号多为跨平台运营；其排版规律与抖音竖屏同类趋同，但无法在本档实证，故未列为核心样例。

## 六、调研说明（手段 / 缺失数据 / 限制）

**成功手段**：
- video_search 抖音知识区/硬核科普：命中 40+ 条，核心 4 条 + 补充 4 条数据完整（赞/评/发布时间/文本结构）。
- B站开放 API（view / related）：实取播放/赞/藏/弹幕/时长/发布时间/账号/封面，当日有效；related API 反查命中"十大恒星/黑洞vs中子星"链接。
- web_fetch B站移动页：确认封面 OCR、弹幕、合集信息。
- Read：精读 5 张 B站官方原封面（坠入奇点/十大恒星/黑洞vs中子星/黑洞之王/老高），均为下载到本地的真实图片。

**缺失数据（如实标注 NA）**：
- 抖音：内帧图与原封面（反爬，见〇）、账号名（video_search 未返回）、播放量（平台隐藏）、收藏/转发数（平台隐藏）→ 抖音样例的赞/评/时间为真实数据，画面细节仅作"推断"并标注。
- B站：黑洞之王（BV11LoWBUEtc，1.49 万播放）未达门槛，未列入核心样例；B站 search API 被风控（返回 HTML 验证页），故个别视频靠 related API 反查。
- 视频号：单条数据全部 NA（无公开接口），仅账号体量级报道。

**限制**：
- 无浏览器（同事独占）、未登录任何平台；未使用任何第三方数据平台付费接口。
- 动画节奏（第 3 步）对抖音样例为"推断"（基于方法论+行业惯例），非帧级实证；B站封面为帧级实证。
- 未照搬任何爆款文案/素材/音乐；预设为通用排版规则，文案位仅占位。
