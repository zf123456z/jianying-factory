### 0.3 跨类型规律归纳（高级感从哪来）

1. **层级克制**：爆款画面普遍只放 2-4 层文字，主标题占最大视觉面积（16-22 号），副层约 62% 比例，绝无"字挤字"。
2. **三角配色系统**：高级模板几乎都是"1 主色 + 1 强调色 + 中性白"（黄/白/红、白/黄/红、白/金/黑），全画面不超 3 色。
3. **动画错峰而非齐发**：入场节奏统一为 0s → 0.5-0.6s → 1.0-1.4s → 1.8-2.0s 递进，常驻不退出（聚蚁式铁律）。
4. **安全线 = 高级感的物理边界**：字号越大越向画面中部收（>16 号压到 ±0.60），大字绝不贴边。
5. **色块底是杂志感的低成本开关**：`background_alpha + background_round_radius` 半透明圆角色块是封面/卡片/要点类高级感的共同手段，引擎已支持。
6. **词级高亮 = 信息密度放大器**：爆款封面普遍用 1-2 个词级红/黄高亮制造视觉焦点（`add_rich_text` 已支持）。
7. **结构增量集中在三类**：多卡并列/序号要点（卡片流）、封面整屏定格（封面）、章节徽标体系（科普）——均为现有库空白。

### 0.4 与现有库的结构增量（一句话版）

- 现有 `DUAL_SCREEN_STYLES` 三档（gold/tech/hot）只有"上下双屏多行常驻"一种骨架 → 本次新增 4 种变体：红黄双色卖点对比档（`contrast`，卖点不再全白）、贴顶头条白字粗描边档（`headline-top`）、身侧大字构图（`side-bigword`，transform_x≠0）、警告清单型 7 层骨架（`warning-list`）。
- 现有 `style_templates.json` 8 条口播模板均为 1-3 层文字 → 本次新增 4-7 层卡片流、封面整屏定格、数字编号要点体系、章节徽标体系，共 14 条可消费条目。
- 平台横向结论：模板平台最先进结构集中在**色块框参数化 + 知识要点卡 + 封面锁版系列**三大块，其中 17/22 我们的引擎已可直接实现，差距集中在贴纸图形轨、转场特效库、混合蒙版三块（详见第六章与配套《模板库扩充建议清单》）。

## 第三章 图文卡片流（小红书 / 抖音图集）
### 一、图文卡片流（小红书图文卡片 / 抖音图集类）

### 0. 图文卡片流是什么（调研界定）

"图文卡片流"= 以**多张图卡连续滑动/并列**为载体的信息排版，特征是：
- 单卡=「图片（人或物）+ 文字标注」的独立信息单元；
- 多卡并列/错峰出现，形成**信息密度梯度**（主图信息量最大，辅助卡逐级补充）；
- 文字承担**导航与转化**职责：店铺名、价格、序号、步骤、标题钩子全部压在图片上；
- 静态为主（图片笔记），动画只发生在"切卡/换图"节奏上；视频化后 = 图片底 + 文字卡片错峰入场。

## 第五章 封面类（小红书 / 全网）
### 二、封面类（视频封面 / 首屏定格排版）

### 0. 封面类是什么（调研界定）

"封面类"= 独立于内容视频的**首屏定格画面**（视频封面 / 信息流第一帧），特征是：
- **大字钩子**：一句话或一个词把利益点/悬念/反差砸到最大字号；
- 人物/产品图 + 色块/描边：文字必须压得住画面（黑描边/底色块/对比色）；
- 层级=钩子大字 → 关键词高亮 → 副标题 → CTA，3 秒内读完。

**五步法拆解**（截图 real1_hanguo_mayi.png，832x468，四屏拼接，首屏即封面）：

- **第1步 画面分区**：封面=上部对比素材区（左"扁塌"马尾 vs 右"饱满"马尾，横向对比，y 0~-0.3）、下部大字标题区"韩国女孩3招|扁头变圆|超显脸小"（y≈-0.65）；内帧还有分步教学小字（"把头发分成两层""立马粗了一倍"）。
- **第2步 文字层级**：
  - 标题"韩国女孩3招|扁头变圆|超显脸小"：主层级，**三行竖排分段**（韩国女孩3招 / 扁头变圆 / 超显脸小），白字黑描边，用"|"分隔节奏；数字"3招"+结果词"超显脸小"是钩子核心；
  - 对比标签"扁塌/饱满"：次层级，位于对比图上，白字黑描边；
  - 分步短句"把头发分成两层/立马粗了一倍"：补充层级，教学卡内白字。
- **第3步 动画节奏**（封面静态 → 视频化规律）：封面标题先出（0s）→ 对比图暗示（0.5s）→ 分步文字逐帧弹出；标题三行可错峰入场（行1→行2→行3，0.3s 间隔）。
- **第4步 素材规则**：同一人物/同一发型做"扁塌 vs 饱满"对比；背景干净（浅色墙）；文字压画面对比区下方，不遮挡脸部。
- **第5步 安全边距**：标题距底 ≈12%；对比图主体（马尾）中心不被文字覆盖；左右边距 ≈5%。

| `hook-stack-cover` 钩子分层大字封面 | center-beat（20号单行大字） | **多行钩子大字堆叠**（17/17/14/12，黑白红交替）+ 关键词双高亮（色块底+换色）；现有 center-beat 仅单行 20 号，无分层堆叠 |

**核心结论**：现有库是"口播上下双屏 + 单行大字 + 左右分屏"三件套；新预设引入四个此前库内不存在的结构能力——**多卡并列（卡片流）、序号要点清单、对比标签色块、封面整屏定格 + 词级圆角色块高亮**。全部基于引擎已确认可用的 `background_alpha + background_round_radius`（半透明圆角色块）、`add_rich_text`（词级高亮）、`add_text`（多轨并列）实现，无需新能力。

### 三、对我们模板库的最有价值增量 TOP5

1. **色块底/圆角背景参数化 = 模板平台的"框与卡"核心工艺**。12 个结构里有 6 个依赖色块/卡片承载文字（封面锁版、金句弹卡、CTA 条、标题框、系列胶囊、要点卡）。我们的 add_text 已支持 background_alpha/background_color/background_round_radius——应系统化沉淀"色块框"预设（半透明黑块底 0.6-0.85、CTA 红条 0.9、胶囊圆角 0.5-1.0），这是零成本最高杠杆的增量（立即落地）。
2. **知识要点卡·编号列表结构**（标题 + 3-4 条编号要点 + 总结）。模板平台与知识赛道交叉强项，适合知识口播/干货内容，我们目前 style_templates.json 无此档——新增 knowledge-point-list 预设，逐条 0.3s 错峰渐显 + 编号高亮（需小改：多行自动布局）。
