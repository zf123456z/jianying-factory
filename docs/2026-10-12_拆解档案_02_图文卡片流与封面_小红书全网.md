## 一、图文卡片流（小红书图文卡片 / 抖音图集类）

### 0. 图文卡片流是什么（调研界定）

"图文卡片流"= 以**多张图卡连续滑动/并列**为载体的信息排版，特征是：
- 单卡=「图片（人或物）+ 文字标注」的独立信息单元；
- 多卡并列/错峰出现，形成**信息密度梯度**（主图信息量最大，辅助卡逐级补充）；
- 文字承担**导航与转化**职责：店铺名、价格、序号、步骤、标题钩子全部压在图片上；
- 静态为主（图片笔记），动画只发生在"切卡/换图"节奏上；视频化后 = 图片底 + 文字卡片错峰入场。

- 笔记原链接：**NA**（无浏览器，无法从小红书站内取原链；证据链=第三方拆解文 + 封面截图，见下）
- 证据来源：人人都是产品经理《小红书爆文拆解:爆文规则改了，都变了天【10月】》https://www.woshipm.com/operate/5185847.html ｜ 封面截图（已下载 Read）：https://aka.doubaocdn.com/s/ofFFXxuUWX

**五步法拆解**（截图 real3_pdd.png，832x468，三屏拼接，其中左/右屏即图卡本体的列结构）：

- **第1步 画面分区**：图卡本体按"列"分区（横向 transform_x 记法）——
  - 左列 x≈-0.45（商品实拍图 + 每张图上叠 价格大字）；
  - 中列 x≈0（博主文案区：引导话术 + 话题标签）；
  - 右列 x≈+0.45（商品图 + 价格列表 + 店铺/款式名，纵向瀑布）。
  - 纵向：图卡中部=商品图区（y 0~-0.3），底部=标题行（y≈-0.85）+ 账号/数据行。
- **第2步 文字层级**（每列内部：价格 > 商品名 > 辅助文案）：
  - 价格数字：主层级，占单格约 12-14% 高度，黑色粗体 + 醒目底色块（红/白底），是整卡第一视觉落点；
  - 商品款式名（如"软糯小奶团开衫"）：次级，细黑字，位于价格上方；
  - 店铺名：三级，小字灰色，置于价格下方；
  - 标题"PDD购物分享｜平价开衫包包✨均价不到30💰"：底部横向条，黑字带强调符号；
  - 关键词高亮规律：数字（价格）用色块底高亮，文字用感叹号/✨符号点缀。
- **第3步 动画节奏**（静态图卡 → 记录"静态排版规律"）：无入场动画；视觉动线=**左上价格 → 商品名 → 店铺 → 下一条目**，Z 字扫读；切卡节奏即抖音图集的"一张一滑"。
- **第4步 素材规则**：真实商品实拍图（上身/平铺）+ 每格独立价格角标；背景统一浅色（米白），不抢文字；点缀=小符号（✨💖）。
- **第5步 安全边距**：左右各留约 5-6% 边距；价格块紧贴商品图角落（≈8% 内缩）；标题条距底边 ≈10%。

## 二、封面类（视频封面 / 首屏定格排版）

### 0. 封面类是什么（调研界定）

"封面类"= 独立于内容视频的**首屏定格画面**（视频封面 / 信息流第一帧），特征是：
- **大字钩子**：一句话或一个词把利益点/悬念/反差砸到最大字号；
- 人物/产品图 + 色块/描边：文字必须压得住画面（黑描边/底色块/对比色）；
- 层级=钩子大字 → 关键词高亮 → 副标题 → CTA，3 秒内读完。

**五步法拆解**（截图 real1_hanguo_mayi.png，832x468，四屏拼接，首屏即封面）：

## 三、与现有模板库的增量对比

现有库（data/style_templates.json，8条口播模板）：pop-yellow / tech-blue / big-impact（22号大字+半透明底+金句高亮）/ segment-highlight / title-subtitle / typewriter / center-beat（20号大字居中）/ split-compare（左右分屏12号）。引擎三档：gold/tech/hot 均为"上下双屏多行常驻"结构。

| 新预设 | 现有最接近 | 明确增量 |
|---|---|---|
| `card-list` 序号要点卡片流 | big-impact（大字+色块底） | **3~4 条半透明圆角色块要点卡多卡并列**（现有库无任何"多卡并列/序号要点"结构）；错峰渐显 0.6→1.5s 制造清单节奏；每条要点可独立高亮 |
| `duet-compare` 双图对比信息卡 | split-compare（左右分屏标题） | 左右**标签色块**（红/蓝圆角底）+ 双图素材分屏 + 对比叙事（现有 split-compare 仅两行标题文字，无标签卡/无图）；"素颜/妆后、Before/After"语义卡 |
| `big-block-cover` 大字纯色块封面 | big-impact（22号大字+色块底） | **封面整屏定格**（无素材视频纯色底）+ 完整封面四层级（22主→20高亮→10副→9CTA）+ **金色圆角色块高亮词**（background_round_radius 词级高亮）；现有 big-impact 是口播常驻层，非封面定格结构 |
| `hook-stack-cover` 钩子分层大字封面 | center-beat（20号单行大字） | **多行钩子大字堆叠**（17/17/14/12，黑白红交替）+ 关键词双高亮（色块底+换色）；现有 center-beat 仅单行 20 号，无分层堆叠 |

**核心结论**：现有库是"口播上下双屏 + 单行大字 + 左右分屏"三件套；新预设引入四个此前库内不存在的结构能力——**多卡并列（卡片流）、序号要点清单、对比标签色块、封面整屏定格 + 词级圆角色块高亮**。全部基于引擎已确认可用的 `background_alpha + background_round_radius`（半透明圆角色块）、`add_rich_text`（词级高亮）、`add_text`（多轨并列）实现，无需新能力。
