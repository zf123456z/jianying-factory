# 爆款调研方法论（剪映工厂 · 同行爆款自主调研 + 拆解）

> 用途：AI 自主在抖音等平台搜索同行爆款视频，理解"什么叫爆款"，
> 拆解爆款的标题钩子/文案结构/画面排版/数据特征，反哺我们的模板与文案。
> 前提：受控窗口浏览器登录抖音（登录态一次扫码，后续全自主）。

## 一、什么叫爆款（量化标准）

抖音隐藏播放量，用点赞/评论/收藏/转发推断量级与质量：

| 点赞量级 | 判定 | 对应播放推断 | 行业垂直(如AI获客)放宽 |
|---|---|---|---|
| ≥10万赞 | 现象级爆款 | 千万级播放 | ≥3万赞即行业爆款 |
| 1万-10万赞 | 爆款 | 百万级播放 | 1万-3万赞=行业热门爆款 |
| 1000-1万赞 | 热门 | 10万-100万播放 | 1000+赞=值得拆解 |
| <1000赞 | 普通 | — | 不拆解 |

**互动质量（更重要）**：
- 收藏/赞比 >10% = 干货型爆款（教程/获客类核心指标；例：9554藏/3.8万赞≈25% 极干货）
- 评论/赞比 >1% = 话题型爆款（引发讨论）
- 转发/赞比 >5% = 传播型爆款（社交裂变）
- 完播率：无法直看，用时长+章节要点推断（10分钟长视频有章节=深度内容留存好）

**爆款四要素**（拆解时逐项核对）：
1. 热点借势：蹭顶级热点（马斯克/大厂发布/行业大事件），时效≤7天
2. 标题钩子：悬念/反差/数字/直击痛点（"马斯克要参战了……"）
3. 内容结构：干货公式/故事化/层层递进（章节化=结构化信息）
4. 人群精准：垂直账号（AI获客号）+ 高收藏 = 精准刚需

## 二、调研工作流（受控窗口浏览器，全自主）

1. **搜索**：`bu.navigate("https://www.douyin.com/search/{关键词}?type=video&sort_type=1")`
   - sort_type=1 为最多点赞排序（爆款优先）
   - 关键词按用户需求：行业词（AI获客/GEO）+ 场景词（口播/带货）+ 竞品词
2. **列表提取**：`bu.read_all("a[href*='/video/']", fields=["href","text"], limit=10)`
   - 记录：标题/点赞/时长/作者/发布时间 → 按点赞排序筛爆款（≥1000赞）
3. **打开爆款**：navigate 视频 URL → `bu.get_page_text()`
   - 提取：完整标题文案、赞/评/藏/转四数、章节要点（抖音AI生成）、时长、发布时间
4. **拆解五维**：
   - 标题钩子（为什么点进来）
   - 文案结构（章节/钩子-干货-转化）
   - 画面排版（如有封面/截图：按《视频视觉拆解方法论》拆文字样式）
   - 数据特征（收藏率=干货型？评论率=话题型？）
   - 转化设计（评论区引导/私信钩子/关键词领取）
5. **归纳落地**：
   - 爆款标题/文案 → 改写库（原创洗稿，不抄袭）
   - 画面排版规则 → DUAL_SCREEN_STYLES 预设
   - 形成"该行业爆款档案"：账号/标题/数据/结构

## 三、产出格式（给用户的爆款报告）

```
【AI获客行业爆款榜】搜索"AI获客"·最多点赞排序 · 2026-10-09
1. 3.8万赞 | 马斯克要参战了…… | @刘姐Ai获客 | 6天前 | 10:27
   ├ 钩子：蹭马斯克热点+悬念
   ├ 数据：3.8万赞/1933评/9554藏/9137转（收藏率25%=纯干货）
   ├ 结构：5章节递进（子午线计划→AI战争→决策→应对→中美合作）
   └ 可借鉴：热点借势+长深度干货
...
【爆款定义速查】≥1万赞=爆款；收藏率>10%=干货型；7天内=热点红利
```

## 四、检查清单
- [ ] 登录态有效（受控浏览器已登录抖音）
- [ ] 搜索结果按最多点赞排序（sort_type=1）
- [ ] 只拆解 ≥1000 赞（行业放宽标准）的视频
- [ ] 四数据（赞/评/藏/转）齐全再下结论
- [ ] 拆解结论可落地（标题改写/样式预设/文案结构）
