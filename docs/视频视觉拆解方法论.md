# 视频视觉拆解方法论（剪映工厂 · 参考视频 → 样式规则）

> 用途：看到任何爆款参考视频（截图/帧/封面），系统拆解其画面内容与文字样式规则，
> 把规则落进模板样式预设，让我们的出片从"结构正确"升级到"审美正确"。
> 适用：聚蚁AI式双屏广告、热点混剪、口播包装等所有带文字排版的短视频。

## 一、拆解五步法（看到参考图必走）

### 第1步 画面分区
- 把画面纵向分成几个文字区 + 素材区？记录每条分区边界（上/中/下）。
- 典型（聚蚁AI式）：上半屏=热点文字区，下半屏=产品文字区，中间=视频素材区。
- 用 y 坐标记录：屏幕顶部=+1.0，底部=-1.0，中线=0（剪映 transform_y 坐标系）。

### 第2步 文字层级（从大到小逐行记）
对每行文字记录：
- 内容（原文）
- 相对字号：以最大行为 100% 基准，其余行按视觉比例估（62% / 56% / 44%…）
- 颜色与用途：黄=主标题/品牌（最醒目），白=正文/卖点（中性），红=强调/CTA/痛点（刺激行动）
- 加粗 / 描边（黑边宽度）
- 位置（y 坐标）与行距（相邻行间距约 0.15-0.18 的 transform_y）

### 第3步 动画与节奏
- 入场动画类型（打字机/渐显/弹入/飞入）
- 错峰节奏：主标题 0s → 副标题 0.6s → 补充 1.2s（依次延迟，制造层次）
- 是否常驻：文字从开始到结束都在，只有入场动画，不退出（聚蚁式铁律）

### 第4步 素材与节奏
- 素材画面内容（人物/产品/大屏/手机/城市…）与热点主题的相关性
- 素材切换节奏（几秒一切，如 18s / 3 素材 = 7s+6s+5s 等分）
- 原片是否静音（是——无配音纯文字广告必静音）

### 第5步 归纳规则 → 落预设
- 把第2-4步的观察写成一条"样式规则"（字号比例/颜色/位置/动画/节奏）
- 更新 `jyfactory/juyi_template.py` 的 `DUAL_SCREEN_STYLES`（或新增样式档）
- 立刻用新预设出片验证 → 视觉对比 → 迭代

## 二、审美规则库（已从爆款验证的通用规则）

### 字号比例（以主标题 16 号为基准 100%）
| 层级 | 相对主标题 | 绝对字号(1080x1920) | 用途 |
|---|---|---|---|
| 主标题 | 100% | 16 | 热点钩子 / 品牌名 |
| 副标题 | 62% | 10 | 补充信息 / 卖点 |
| 补充句 | 56% | 9 | 细节 / CTA 小字 |
| 品牌行 | 87% | 14 | 产品品牌常驻 |
| 卖点行 | 59% | 9.5 | 产品功能卖点 |

### 颜色搭配（黑描边底，高对比）
- 黄 #FFD400：主标题/品牌——全画面最亮，第一眼看到
- 白 #FFFFFF：副标题/卖点——中性信息层
- 红 #FF3B30：痛点/CTA——刺激点，占比最小（<20% 面积）
- 蓝 #4FC3F7：科技感主题（AI/数码热点备用档）
- 描边：主标题 0.8，其余 0.6（黑色描边保证白字/黄字在任何素材上都清晰）

### 位置与安全线（1080x1920，transform_y）
- 上半屏热点区：主标题 +0.75，副标题 +0.55，补充 +0.40（向下排）
- 下半屏产品区：品牌 -0.40，卖点1 -0.58，卖点2 -0.70，CTA -0.82（向下排）
- 字号安全线（超出自动收敛）：≤10 号 ±0.80；11-16 号 ±0.75；>16 号 ±0.60
- 原则：任何文字不贴屏幕边缘（留 ≥5% 边距），不互相遮挡

### 动画错峰节奏
| 顺序 | 入场 | 延迟 | 目的 |
|---|---|---|---|
| 主标题/品牌 | 打字机 | 0.0s | 第一视觉落点 |
| 副标题 | 渐显 | 0.6s | 补信息不抢主标题 |
| 补充/卖点1 | 弹入/渐显 | 1.0-1.4s | 第三层次 |
| CTA | 弹入 | 2.0s | 最后收口，引导行动 |
- 铁律：全部常驻不退出；动画只在入场，不做退场动画

### 素材规则
- 无配音纯文字广告：原片强制静音（volume=0.0）
- 素材与热点主题语义相关（AI热点→AI员工/大屏/手机素材）
- 素材数量=切分数，时长等分铺满（18s/3=7+6+5s），循环铺满不留黑屏

## 三、工作流（用户给参考图/视频时）

1. 先按"拆解五步法"观察参考图（Read 图片 → 逐区记录）
2. 提取规则 → 更新 DUAL_SCREEN_STYLES 预设（或现场临时覆盖参数）
3. 用新预设出片 → 部署草稿箱 → 静态验证（文字常驻/不越安全线/时长对齐）
4. 向用户汇报"这次从参考里学到了什么规则、怎么落地的"

## 四、检查清单（出片前自查）
- [ ] 文字全部常驻（0~duration），只有入场动画
- [ ] 字号层级分明（主>副>补充；品牌>卖点>CTA）
- [ ] 颜色对比合理（黄/白/红三档，黑描边）
- [ ] 无文字越安全线、无互相遮挡
- [ ] 原片静音、BGM 铺满与视频同长
- [ ] 素材与热点语义匹配
