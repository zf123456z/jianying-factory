# 模板库扩充建议清单（2026-10-12）

> **剪映工厂 · 模板库扩充专项 · 落地决策建议**
> 配套文档：《高级模板拆解档案_2026-10-12.md》（22 条预设全量拆解）。本清单回答三个问题：**先落哪些、各需多少开发量、按什么顺序做**。
> 落库路径共 4 级：①`style_templates.json` 加条目（纯数据，引擎直接消费）②`jyfactory/juyi_template.py` 的 `DUAL_SCREEN_STYLES` 加档（代码级，produce_hotspot_ad 直接消费）③新类型写 `produce_*` 编排函数 + `examples/` 演示脚本（仿 `produce_hotspot_ad` 全链路：建稿→素材→文字→BGM→部署）④`TemplateManager` 草稿克隆（49 个明文草稿可直接克隆换内容，适用于需要完整保留花字/特效/关键帧的成品模板）。

## 一、结论先行

- **推荐首批落库（P0）10 条**：全部为"3 分钟可实现"档、覆盖全部 5 大类型，纯数据级/代码级改动，**预计 2 个工作日完成全部落地 + 出片验证**。
- **P1（次周）10 条**：平台结构高价值条目 + 需小改条目，**预计 3 个工作日**。
- **P2（暂缓）2 条**：依赖 VectCutAPI 新能力（混合蒙版 / 转场特效库 / 节拍识别），同步向引擎侧提需求，到位后各约半天落地。
- **质量防线**：每条落库必须过"出片 → `draft_checker` 静态检查（文字常驻/不越安全线/时长对齐）→ 部署草稿箱 → 视觉验收"四步，宁缺毋滥（本次调研的 22 条已全部通过引擎铁律预校验，落库阶段不再重复筛）。

## 五、引擎能力缺口清单（驱动 VectCutAPI 扩展，按价值排序）

1. **混合蒙版 / 镂空渲染**：支撑镂空大字开幕、杂志感混叠（缺口：blend/mask 关键帧属性）——最高价值，解锁剪映模板中心招牌玩法。
2. **转场特效资源库 + 节拍识别**：支撑卡点变装/图文快闪的"踩点切换"（缺口：转场资源枚举 + 音频节拍检测 API）。
3. **贴纸/图形轨**：箭头、对勾、图形点缀（缺口：贴纸资源 + 独立图形轨）——成本最低的"高级感补全"，多条封面模板等待。
4. **风格化字体档**：手写体/综艺体等（缺口：font 枚举扩展，需先确认剪映字体库可用项）——低难度、快见效。

## 六、落地顺序建议（3 天节奏）

- **Day 1（纯代码/数据，见效最快）**：`contrast` + `headline-top` 双屏两档（dict 直加）→ `warning-list` + `side-bigword` 口播两条（JSON 直加）→ 各出一条验证片。
- **Day 2（新类型编排）**：`card-list`、`big-block-cover`、`hook-stack-cover` 三条（写 produce_* 函数 + examples 脚本）→ 出片验证。
- **Day 3（科普 + 平台结构）**：`knowledge-card`、`chapter-flow`（含章节分段调度）→ P1 中 3-5 条高价值平台条目 → 全套回归验证。
- **并行**：向 VectCutAPI 侧提新能力需求（蒙版/转场/贴纸/字体档），P2 条目按依赖解除顺序跟进。

## 七、落库验收标准（每条必过）

1. `style_templates.json` 新条目通过 `python json.loads` + 引擎消费测试（读入不报错）。
2. `DUAL_SCREEN_STYLES` 新档通过 `produce_hotspot_ad(style=新档)` 实际出片，草稿在剪映可正常打开。
3. 新类型模板（卡片流/封面/科普）：examples 演示脚本可一键出片；`draft_checker` 静态检查全绿（文字常驻 0~duration / 不越安全线 / 时长对齐 / 原片静音 / BGM 铺满）。
4. 视觉验收：按《视频视觉拆解方法论》检查清单逐项过（层级分明 / 配色≤3 色 / 无遮挡 / 素材语义匹配）。
5. 每条模板在 SKILL 文档补充"适用场景一句话 + 参数说明"，保证用户一句话即可调用。

## 八、方法论回填（本次调研沉淀，防重复踩坑）

1. **热点双屏类"爆款稀缺"事实**：经 6+ 轮检索（15+ 关键词）与浏览器"最多点赞"排序确认，聚蚁式纯文字双屏打法全网**无 ≥1 万赞同结构自然爆款**——该结构是投流素材，自然互动天然低。未来此类调研不再期待自然爆款，按"行业垂直 + 官方矩阵最高赞"标准执行。
2. **视频号无公开数据接口**：单条视频赞/播放不可得，只能按账号体量级判断，此类调研如实降级。
3. **抖音网页反爬确认**：分享页 jsvmprt 混淆页 + aweme API 空响应（均实测），关键帧截图需走浏览器 seek 截帧（本次已成功），分享页 URL 直取画面不可行。
